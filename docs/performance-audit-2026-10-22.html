What changed

  • Added responsive WebP derivatives and layout-specific srcset/sizes for 32 source images: process-page illustrations, the newsletter, team portraits, consultation image, feature icons, client logos and the advisor portrait. Original source URLs remain available.
  • The twelve client-logo files selected at desktop/mobile DPR 1 now total 43 KB, down from 188 KB. Logos, colors, wording and the marquee layout are preserved.
  • The shopper-question illustration now selects its existing smaller WebP on narrow screens. Product demonstration crop and swatch behavior remain unchanged.
  • Kept hero images eager and high priority; kept below-the-fold media lazy. Added asynchronous decoding where missing.
  • Corrected Alex and Eduard’s homepage image dimension attributes to match their actual 800 × 600 source files. Their displayed sizes and crops are unchanged.
  • Expanded the image sitemap from four homepage-only images to 26 relevant images across all five indexable pages. Removed deprecated image-title/caption sitemap extensions and updated the homepage modification date to its actual revision date.
  • Added reliable Open Graph image/alt fallbacks and image dimensions for the shared 1200 × 630 preview, without changing page titles, descriptions or visible copy.
  • Added repeatable asset audits and content-preservation tests. Updated stale homepage test expectations to the already approved page content; no editorial changes were made.

Remaining checks after deployment

  • Measure the deployed website with PageSpeed Insights and real-user Core Web Vitals, including actual consent scripts and any consented analytics. The local audit deliberately prevents real vendor calls and submissions.
  • Verify production HTTPS redirects, compression, caching headers, the live robots file and canonical host. These are controlled by hosting and cannot be confirmed from the local build.
  • Submit or refresh the sitemap in Google Search Console and inspect the key pages for indexing. Local crawlability checks cannot confirm Google indexing or rankings.
  • The homepage hero video is 728 KB and remains the largest initial asset. It was preserved to retain the requested visual content and autoplay behavior.
  • Thirteen original PNG files total 18.07 MB in public/. None is referenced by page markup; current pages use WebP. They were retained for source quality and regeneration, so they add deployment storage rather than measured page-transfer weight.
  • The existing Windows cold-build picomatch resolution issue occurred on the first build attempt; the second production build passed. It was present before this audit and is not an image or SEO defect. If it recurs in a clean deployment environment, investigate dependency resolution separately.
